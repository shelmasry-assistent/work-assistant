# 💼 المساعد الذكي للعمل والمراسلات والعقود (Work Assistant Agent)

تم بناء وتخصيص هذا المساعد الذكي ليفهم طبيعة عملك ونظامك بالكامل (إدارة الخطابات، العقود، المواعيد النهائية، وقاعدة بيانات أوراكل).

---

## 📁 محتويات النظام:
1. **`web_agent.py`**: واجهة ويب تفاعلية حديثة ومتكاملة باللغة العربية (RTL) للدردشة مع المساعد ورفع الملفات بضغطة زر.
2. **`agent.py`**: تشغيل المساعد من موجه الأوامر (Terminal) مباشرة.
3. **`knowledge_base/`**: قاعدة المعرفة التي يتعلم منها المساعد:
   - `about_my_work.md`: مسؤولياتك وأهدافك اليومية.
   - `system_rules.md`: قواعد دورة حياة الخطابات (الوارد، الصادر، الأولوية، والسرية) وفترات تنبيهات العقود (60، 30، 7 أيام).
   - `database_schema.md`: هيكل جداول أوراكل (CONTRACTS, LETTERS, DEPARTMENTS).
4. **`run_web.bat`**: ملف تشغيل سريع بنقرة واحدة على ويندوز.

---

## 🚀 طريقة التشغيل لأول مرة:

### 1. تثبيت المكتبات (مرة واحدة فقط):
افتح موجه الأوامر في هذا المجلد ونفذ:
```bash
pip install -r requirements.txt
```

### 2. وضع مفتاح Gemini API:
- احصل على مفتاح مجاني من: [Google AI Studio](https://aistudio.google.com/)
- أنشئ ملف `.env` وضع المفتاح داخله:
  ```env
  GEMINI_API_KEY=AIzaSy...
  ```
- أو يمكنك إدخال المفتاح مباشرة من واجهة الويب في الشريط الجانبي.

### 3. التشغيل:
- **لتشغيل واجهة الويب:**
  انقر نقراً مزدوجاً على **`run_web.bat`**
  أو اكتب في سطر الأوامر:
  ```bash
  streamlit run web_agent.py
  ```
- **لتشغيل نسخة الطرفية (Terminal):**
  ```bash
  python agent.py
  ```
